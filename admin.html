변경 요청 승인

변경 내용을 확인하고, 승인한 자료만 확정 데이터에 반영합니다.

관리자의 요청도 별도 승인이 필요합니다.

관리자는 본인 요청을 직접 승인할 수 있습니다. 제출과 승인 시 서버에서 형식·제약조건·충돌을 검증합니다. 원본 증빙과 업무 내용의 정확성은 검토자가 확인해 주세요.

WeKeep 자동 원본 수집은 별도 조회용 자료로 유지됩니다. 승인된 업무 데이터 변경만 기존 시트 동기화에 반영됩니다.

회사 계정 로그인 확인

대시보드와 같은 브라우저의 로그인 상태를 확인합니다. 로그인되어 있지 않다면 대시보드에서 로그인 후 이 페이지를 다시 열어 주세요.

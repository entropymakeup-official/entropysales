# 거래처 연락처

사용자 2026-09-17 승인: 거래처 연락처 별도 메뉴를 만들고 직접 입력과 엑셀·CSV 업로드를 포함해 진행.

거래처 마스터 아래 연락처 메뉴에서 업체별 여러 담당자를 조회·검색하고 등록·수정한다. 기존 거래처 연결은 선택이며 미등록 업체도 저장한다. 필드는 company, person, person_en, title, duty, department, country, mobile, phone, fax, email, messenger, website, address, tags, note, status, customer_id. 업체·담당자와 연락수단 한 가지 필수. 상태는 활성/퇴사·변경/보류.

직접 입력과 파일 업로드 버튼을 분리한다. XLSX/XLS/CSV 첫 줄 머리글 자동 매핑, Google/Outlook 이름 인식, UTF-8 및 한국어 CSV 인코딩 선택, 여러 시트 선택, 전화번호 문자열 보존, 미리보기/행 선택/중복·오류 표시, 빈 양식 다운로드. 최대 15MB/5,000행, 저장 요청은 최대 1,000건 및 5MB로 나눠 처리한다. 업로드 중 파일 교체·닫기·중복제출 방지. 기존 값 덮어쓰기 없음. 중복은 이메일 또는 업체+담당자 기준이며 검토 경고로 분류한다.

기존 ChangeRequests 및 관리자 승인 정책을 그대로 사용한다. 승인 전에는 확정 연락처에 존재하지 않으므로 화면에 승인 대기와 접수 완료를 명시한다. 같은 세션 및 조회 권한이 있는 기존 대기 요청과 중복 재접수를 방지한다. 일반 회원은 본인 요청만 조회하며 다른 사용자의 대기 요청과의 중복은 DB가 승인 시 차단한다. 부분 실패 시 접수된 항목을 제외하고 실패한 항목만 재시도한다. 인증 변경은 상태/입력/미리보기 초기화. 연락처 데이터는 공개 저장소에 넣지 않는다.

DB contacts는 기존 approval_private.identity를 통한 회사 계정 읽기만 허용하고 직접 쓰기는 금지, 기존 승인 경로만 허용한다. DB 제약 및 인덱스로 중복·잘못된 필수값 방지. 기존 영업 데이터와 대기 승인 요청 수정 없음.

검증: 모델/가져오기/동시성 단위테스트, PGlite 승인·권한·중복·stale 변경 테스트, 전체 회귀 및 문법검사, 브라우저 합성자료로 직접입력/파일검토/실패복구/반응형 확인. 운영에는 테스트 연락처를 저장하지 않는다.
